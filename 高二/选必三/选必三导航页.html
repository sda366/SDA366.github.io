教材定位
《义务教育历史课程标准》与统编教材体系下，选择性必修3《文化交流与传播》在必修课程基础上，引导学生了解人类文化交流与传播的基本途径、主要方式与特点，理解文化交流与互鉴在文明进步中的重要作用。全册 15 课按"中华文化→世界文化→人口迁徙→商路贸易→战争交锋→传承保护"六个视角展开，课与课之间以"文化交流与传播"为主线层层递进、前后贯通。本导航页重点呈现各课"承接什么、引出什么"的脉络联系，便于整体把握与复习回扣。

主线逻辑 主体（U1）先认清"自己的文化"特质与意义 → 空间（U2）横向看见世界多样文化 → 人口（U3）人如何流动带来文化交融 → 商路（U4）物如何流动带来文化交流 → 战争（U5）冲突如何倒逼文化碰撞 → 保护（U6）文化成果如何传承与共同守护。前四单元是"交流的三种路径"，第五单元是"交流的冲突形态"，第六单元是"交流的归宿与守护"，首尾呼应 L1 中华内涵与 L15 人类共同财富，形成闭环。

全册根基：从"中华"看世界，为后续所有"文化交流"提供主体坐标。

前后联系单元之间与课与课的关键连接点

连接位置连接的课 / 单元贯通要点
U1 内第1课 → 第2课从"中华内涵"（主体）到"中华世界意义"（辐射），完成由内而外的视野转换。
U1→U2第2课 → 第3课由"中华文化世界意义"自然转入"世界其他文化"，开启横向空间展开。
U2 内第3→4→5课地理递进：西亚非洲（文明源头）→ 欧洲 → 南亚东亚美洲，体现文化多样性与独立发展。
U2→U3第5课 → 第6课从"静态的多样文化"转向"动态的人口迁徙如何塑造文化"，交流路径由空间转时间。
U3 内第6→7→8课时间轴：古代和平迁徙 → 近代殖民暴力重构 → 现代劳动力全球流动与多元认同。
U3→U4第8课 → 第9课由"人的流动"补充"物的流动"（商路贸易），和平交流路径登场，与 U3 暴力重构对照。
U4 内第9→10课从古代丝路到近代全球贸易网，"商品流动先于知识流动"贯穿，交流规模化、规则化。
U4→U5第10课 → 第11课由"和平贸易交流"转入"战争冲突交流"，同是交流却形态迥异，形成全书最强对照。
U5 内第11→12→13课时间轴：古代客观交融 → 近代主观征服/文化侵略 → 现代民族觉醒与新兴国家文化。
U5→U6第13课 → 第14课由"文化在冲突中碰撞"转向"文化如何被传承与保护"，进入归宿性单元。
U6 内第14→15课由"传承载体"（学校/书籍/图博）升华为"遗产保护"（人类共同财富）。
首尾呼应第1课 ⇄ 第15课起点"中华内涵"与终点"人类共同财富"遥相呼应，闭环于"各美其美→美美与共→共同守护"。
