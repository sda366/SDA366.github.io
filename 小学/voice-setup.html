📱 手机听不到声音？

Edge 浏览器 + 讯飞语记 · 已在安卓手机上实测可行

✅ 照这 4 步做，就能听到声音

在手机上打开 www.jeepsh.cn，小学课件如果听不到声音，推荐下载 Edge 浏览器和讯飞语记。

先说结论：用 Edge 浏览器打开本站，再装一个会说中文的讯飞语记， 并在讯飞语记里打开两个开关，手机就有中文朗读了。
1
用 Edge 浏览器打开本站 网址：www.jeepsh.cn（没装 Edge 就到应用商店搜「Edge」免费安装） 如果是在微信 / QQ 里打开的，点右上角「⋯ → 在浏览器打开」，选 Edge。 这类 App 的内置浏览器没有朗读功能，点了必然没声音。
2
安装讯飞语记 应用商店搜索：讯飞语记 → 安装
3
在讯飞语记里打开两个开关、选发音人 讯飞语记 › 通用设置 › 语音合成设置
→ 打开「合成系统接口」和「全局生效」两个开关
→ 再选一个中文发音人 这两步是关键：打开后，等于给手机系统装了一个会说中文的语音引擎，Edge 才能调用它出声。
4
试听 + 重启浏览器 系统语言设为简体中文 → 点「播放」试听，确认能说中文
→ 彻底关闭浏览器再重开（后台划掉）→ 回到课件点读 必须后台划掉重开一次，新的语音引擎才会被浏览器认到。
🔊 顺手确认两件事：①朗读走的是媒体音量，按侧键把媒体音量调大，别是静音/勿扰； ②别连着蓝牙耳机（声音可能跑到耳机里去了）。

🔧 不想装讯飞语记？试试系统自带引擎

小米 / Redmi 自带「小爱同学语音引擎」，也能用

1
设置里搜「文字转语音」 设置 › 更多设置 › 语言与输入法 › 文字转语音（TTS）输出 部分版本在：设置 › 更多设置 › 无障碍 › 文字转语音输出。各品牌都可在设置顶部搜索框直接搜「文字转语音」。
2
首选引擎选「小爱同学语音引擎」（或讯飞语音引擎）， 语言选 中文（普通话）；若提示下载语音数据，务必下载（约几十 MB）。
3
点「播放」试听，能听到中文女声 → 彻底关闭浏览器重开 → 回课件点读。
⚙ 一键打开系统朗读设置

🧭 现象速查

现象原因怎么办
微信里怎么点都没声微信/QQ 内置浏览器不支持朗读右上角「⋯ → 在浏览器打开」，选 Edge
字幕在动但没声音系统没有中文语音引擎装讯飞语记，打开「合成系统接口」「全局生效」
读英文腔 / 读得像外语默认语音不是中文发音人选中文，系统语言设为简体中文

读几句突然停切到后台 / 电池优化限制保持浏览器在前台
能听到中文一切正常把本页加入书签，方便以后查

🍎 iPhone / iPad

1
关掉侧边静音拨杆（看不到橙色即为已开声）——这是 iPhone 无声的第一原因。
2
设置 › 辅助功能 › 朗读内容 › 打开「朗读所选项」，并在「声音 → 中文」里下载一个中文语音。
3
iPhone 上 Safari / Chrome / Edge 都支持朗读，任选其一；若仍无声，同样按上面装讯飞语记的办法试一次。

🆘 还是没声音？

打开「声音自检」页，它会自动报出：用的哪个浏览器、有没有中文语音、试听结果。
