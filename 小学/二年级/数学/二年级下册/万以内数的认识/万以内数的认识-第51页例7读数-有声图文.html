× 🔊 手机听不到声音怎么办？
① 先把手机媒体音量调大，确认没开静音、没连蓝牙耳机；在微信里打开的，点右上角「⋯ → 用浏览器打开」。
② 还是没声音？到应用商店免费下载 Microsoft Edge 浏览器（它自带朗读发声），用它打开本页面就能出声。
③ 换了 Edge 仍然没声音，说明这部手机的硬件/系统不支持网页朗读（多为老旧机型）；近几年买的新手机一般都能正常播放。 → 打开声音自检

读法万以内的数怎么读？黄框里说了哪四条？ 看答案 ▾
① 从高位读起，按照数位顺序读
② 千位是几读几千，百位是几读几百……
③ 中间有一个 0 或两个 0，只读一个零
④ 末尾不管有几个 0，都不读
💡 先看有没有零，再看零在中间还是在末尾。

分层提问练习（先想后看解析）
🔢 认知3745 是由几个千、几个百、几个十和几个一组成的？怎么读？ 看解析
🤔 想一想
怎么想的：先看计数器每一档有几颗珠子，说出组成；再从高位读起，千位读几千、百位读几百，一位一位往下读，最后连成一句话。
解析：
3 个千、7 个百、4 个十、5 个一
读作：三千七百四十五
0️⃣ 认知2080 读作什么？末尾的零要不要读？ 看解析
🤔 想一想
怎么想的：先把每一位上的数说清楚，再看零在哪。百位的零夹在千位和十位中间，要读；个位的零在最末尾，不读。
解析：
2 个千、0 个百、8 个十、0 个一
读作：二千零八十（中间的零读，末尾的零不读）
🔍 强化6009 中间有两个零，读的时候读几个零？为什么？ 看解析
🤔 想一想
怎么想的：先找零的位置：百位和十位都是零，两个零连在一起，夹在千位和个位中间，属于中间有零的情况，按规则只读一个零。
解析：
6 个千、0 个百、0 个十、9 个一
读作：六千零九（两个零只读一个）
📖 强化4900 和 5002 分别怎么读？两个数的零有什么不一样？ 看解析
🤔 想一想
怎么想的：先分清零在末尾还是在中间。末尾的零一个也不读，中间的零要读而且只读一个，位置不同，读法就不同。
解析：
4900 → 四千九百（末尾两个 0 都不读）
5002 → 五千零二（中间两个 0 只读一个零）
🧩 强化3604 和 1050 分别怎么读？各是由几个千、几个百、几个十和几个一组成的？ 看解析
🤔 想一想
怎么想的：先说出每一位的组成，再看零的位置：十位上的零在中间要读一个零；个位上的零在末尾不读，读的时候别把它带出来。
解析：
3604 = 3 个千、6 个百、0 个十、4 个一 → 三千六百零四
1050 = 1 个千、0 个百、5 个十、0 个一 → 一千零五十
🚀 拓展五岳的海拔里，哪个数读的时候要读零？为什么其他数不读零？ 看解析
🤔 想一想
怎么想的：把五个数一位一位看过去，先找有没有零，再看零在中间还是在末尾。只有零在中间、前面还有数的，才要读出一个零。
解析：
只有 2016 → 二千零一十六，百位的零在中间，读一个零
1533、2155、1492 中间没有零；1300 的零在末尾，不读
