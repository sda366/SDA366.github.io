💡 先找最高位，再一位一位往下写；哪一个数位上一个也没有，就写 0 占位。
讨论万以内的数怎么写？ 看答案 ▾
① 从高位写起，按数位顺序写
② 几千就在千位上写几，几百就在百位上写几……
③ 中间或末尾哪一位上一个也没有，就在那一位上写 0
💡 三条合起来就是：先数计数单位的个数，再对号入座，空位补 0。
机器人“写出计数单位的个数”是什么意思？ 看答案 ▾
三千零六十九：3 个千、0 个百、6 个十、9 个一 → 3069
💡 说“几个千、几个百、几个十、几个一”，就是在报每一位上的数。
做一做1星星、大熊猫、蛟龙号各写多少？ 看答案 ▾
(1) 七千 → 7000
(2) 一千八百六十四 → 1864
(3) 七千零六十二 → 7062
💡 7000 的百位、十位、个位都写 0；7062 只有百位写 0。
分层提问练习（先想后看解析）
✍️ 认知三千零六十九中间有一个零，百位上写几？ 看解析
🤔 想一想
怎么想的：先找这个数里有数的数位：只有千位、十位、个位有数。百位上一个单位也没有，就要写零占住位置，不能空着。
解析：
三千零六十九：千位写 3，百位写 0，十位写 6，个位写 9。
所以写作 3069。中间有 0 的数，写数时零要写出来，读数时读一个零。
🔢 认知二千七百末尾的两个零能不写吗？ 看解析
🤔 想一想
怎么想的：二千七百只有千位和百位有计数单位，十位、个位都是空的。按规则，末尾哪一位上一个也没有，也要写零占位。
解析：
千位 2、百位 7、十位 0、个位 0。
写作 2700，末尾两个 0 一个也不能省；省掉就变成 27，意思全变了。
🧮 强化七千零一为什么写成 7001，中间两个零各占哪一位？ 看解析
🤔 想一想
怎么想的：七千零一里，千位是七，个位是一，中间百位和十位都没有计数单位。这两个空位都要用零占住。
解析：
千位 7 → 百位 0 → 十位 0 → 个位 1。
写作 7001。中间连续两个 0，读的时候只读一个零。
🔟 强化5 个千、8 个百、0 个十、3 个一组成的数写作多少？ 看解析
🤔 想一想
怎么想的：题目把每个数位上的数都报出来了，只要对号入座。哪一位报的是几个，就在那一位写几；报的是零个，那一位就写零。
解析：
5 个千 → 千位 5；8 个百 → 百位 8；0 个十 → 十位 0；3 个一 → 个位 3。
写作 5803，读作五千八百零三。
📏 强化数轴上 0 到 1000 是一大格，后面依次填几？每一小格表示多少？ 看解析
🤔 想一想
怎么想的：数轴上先认一大格和一小格各是多少。零到一千是一大格，分成十小格，就知道一小格是一百。
解析：
一千分成十份，每份一百，所以一小格表示 100；四大格依次是 2000、3000、4000、5000。
3700 从 3000 往右数 7 小格；6500 在 6000 与 7000 中间；9900 在接近 10000 处。
⭐ 拓展用两个 8 和两个 0 组成四位数，能写出哪几个？哪个数里的零一个也没读出来？ 看解析
🤔 想一想
怎么想的：四位数千位不能是零，所以千位先定 8。剩下的一个 8 和两个 0 去排百位、十位、个位。
解析：
可能的排法：8800、8080、8008。
8800 末尾两个 0 都不读；8080 读八千零八十；8008 读八千零八。
💡 千位不能是 0，这是四位数的一条硬规矩。
