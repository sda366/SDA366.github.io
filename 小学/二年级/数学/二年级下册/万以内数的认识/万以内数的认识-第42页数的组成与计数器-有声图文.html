组成这个数由几个百、几个十、几个一组成？ 看答案 ▾
2 大捆＝2 个百；3 小捆＝3 个十；5 根＝5 个一；
括号里依次填 3 和 5；
💡 先看整捆、再看小捆、最后数单根，就不会数乱。
读写235 怎样在计数器上表示？怎么写、怎么读？ 看答案 ▾
百位 2 颗、十位 3 颗、个位 5 颗；
写作 235，读作 二百三十五；
💡 哪一位上有几个单位，就在那一位上拨几颗珠子，写数时对齐数位。
易错中间有0、末尾有0，怎么读？ 看答案 ▾
384 读作 三百八十四（各位都有数，直接读）；
406 读作 四百零六——中间有 0 要读零；
590 读作 五百九十——末尾的 0 不读；
💡 0 在中间要出声，0 在末尾不出声。
数数199 的后面为什么是 200？ 看答案 ▾
198 → 199 → 200 → 201 → 202 → 203；
199 再添 1，个位满十、十位满十、百位进一，所以变成 200；
💡 满十要向前一位进一，这叫“满十进一”。

🧮 认知计数器上百位 4 颗、十位 0 颗、个位 6 颗，这个数写作什么？读作什么？ 看解析
🤔 想一想
怎么想的：先按百位、十位、个位读出每位的颗数，再看十位没有珠子要用零占位，最后按中间有零的读法读出来。
解析：
百位 4、十位 0、个位 6，写作 406（十位的 0 不能丢）。
中间有 0 要读零，读作 四百零六。
🔢 强化从一百九十八起，一个一个地数到二百零三，中间要经过哪些数？ 看解析
🤔 想一想
怎么想的：先想一个一个数就是每次添一，再想一百九十九添一会不会进位，最后把经过的数按顺序写出来。
解析：
198、199，199 添 1 满十进一，得到 200。
接着 201、202、203，所以中间经过 199、200、201、202。
⏫ 强化从二百二十起，一十一十地数到三百一十，一共要数几次？ 看解析
🤔 想一想
怎么想的：先想一十一十地数就是每次添一个十，再一位一位往下数，最后数一数一共添了几次十。
解析：
220、230、240、250、260、270、280、290、300、310。
一共添了 9 次十；290 再添十，十位满十进一，得到 300。
⚠️ 强化为什么 406 要读零，而 590 不读零？ 看解析
🤔 想一想
怎么想的：先看零在哪一位，再想不读会变成哪个数、会不会听错，最后总结中间零和末尾零的读法。
解析：
406 的 0 在中间，不读就成了四百六，容易听成 460。
590 的 0 在末尾，末尾的 0 不读；中间的 0 必须读。
🚀 拓展从三百零八开始，连续数出后面五个数。 看解析
🤔 想一想
怎么想的：先想连续数就是每次添一，再想个位满十要进到十位，最后按顺序写出五个数。
解析：
308、309，309 添 1 个位满十进一，得到 310。
再数 311、312、313，共五个：309、310、311、312、313。
