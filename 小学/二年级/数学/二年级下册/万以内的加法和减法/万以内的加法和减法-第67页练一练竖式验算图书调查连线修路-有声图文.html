➕ 认知列竖式算 745+129，并验算。 看解析
🤔 想一想
怎么想的：先从个位算，五加九满十要进一；再算十位，别忘加进上来的一；最后算百位。凭什么验算？两个加数交换位置，和应该不变，两次一样才算对。
解析：
5+9=14，写 4 进 1；4+2+1=7；7+1=8。
745+129=874；验算 129+745=874，两次相同，算对了。
🤔 认知838+172 为什么得 1010，中间的 0 从哪来？ 看解析
🤔 想一想
怎么想的：先算个位八加二，正好满十写零进一；再算十位三加七再加一，得十一，写一进一；最后算百位八加一再加一，又是十。凭什么有零？哪一位算出十就写零。
解析：
8+2=10，写 0 进 1；3+7+1=11，写 1 进 1；8+1+1=10，写 0 进 1。
838+172=1010，十位上的 0 是算出来写下的，不能省，也不能写成 110。
得数里有 0 的题，一定要一位一位对齐写

🕊️ 强化连一连：236+374、547+169 各连哪个数？（可选：610、716、810、995、451） 看解析
🤔 想一想
怎么想的：先一道一道算出得数，写好再去找下面相同的数，不要凭眼睛猜。凭什么这样连？得数是唯一的，算准了才能一一对上。
解析：
236+374：6+4=10 进 1；3+7+1=11 进 1；2+3+1=6 → 610
547+169：7+9=16 进 1；4+6+1=11 进 1；5+1+1=7 → 716
两道题都进了两次位，连完回头核对一遍
🛠️ 强化要维修长 840 米的道路，上午修了 356 米，下午修了 278 米。上午和下午一共修了多少米？ 看解析
🤔 想一想
怎么想的：先把问题读清楚，问的是上午和下午「一共」，那就把两段合起来；再想 840 米是全长，这里用不上。凭什么不用它？问题没问还剩多少。
解析：
356+278：6+8=14 进 1；5+7+1=13 进 1；3+2+1=6 → 634（米）
答：上午和下午一共维修了 634 米。840 米是多余条件，这题用不上。
✍️ 拓展把第 5 题改成一个「还剩多少米没修」的问题，并解答。 看解析
🤔 想一想
怎么想的：先看清「还剩」要用减法，被减数是全长；再先算出已经修了多少，然后才做减法。凭什么先加后减？减法要用到已经修的米数，这个数题里没直接给。
解析：
已修：356+278=634（米）；还剩：840-634=206（米）。
答：还剩 206 米没修。同一个 840 米，换个问题就从多余条件变成了必须用的条件。
拓展：条件用不用，由问题决定，不由条件多少决定
