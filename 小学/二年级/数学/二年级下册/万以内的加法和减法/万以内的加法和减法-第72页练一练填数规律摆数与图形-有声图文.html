巧算加 199 为什么最后减 1？减 398 为什么最后加 2？ 看答案 ▾
156+199：199 比 200 少 1 → 156+200-1 = 356-1 = 355
537-398：398 比 400 少 2 → 537-400+2 = 137+2 = 139
同组两题结果一样：156+199=355，156+200-1=355；537-398=139，537-400+2=139
💡 多加的要减回来，多减的要加回来；先算整百，再补差数。
填数□6□+3□4=803，方框该从哪一位想起？ 看答案 ▾
从个位起，进位是钥匙：
(1) 个位 □+4 得 3 → 满十，13 → □=9，进 1；十位 6+□+1=10 → □=3；百位 □+3+1=8 → □=4 → 469+334=803
(2) 894-423=471：个位 4-□=1 → □=3；十位 □-2=7 → □=9；百位 □-4=4 → □=8
(3) 945+45=990：个位 5+5=10 写 0 进 1；十位 4+□+1=9 → □=4；百位 □+0=9 → □=9
💡 先个位、再十位、后百位，每一步都问一句：满十了吗？退位了吗？
估算只摆最高位，和与差各接近多少？ 看答案 ▾
方法：只摆最高位 = 只看千位 → 把两个数看成整千数再算
示例：百位 6 与百位 3 → 看成 6000 与 3000 → 和接近 9000，差接近 3000
换卡片（如 2 与 9）→ 看成 2000 与 9000 → 和接近 11000，差接近 7000
💡 卡片不同，估出的数也不同，这题没有唯一答案；说清「看成哪两个整千数」就算对。
图形算式○8○+△□○=△□○8，三个图形各是几？ 看答案 ▾
个位 ○+○ 得 8 → ○ 是 4（不进位）或 9（9+9=18）
试 ○=4：十位 8+□ 要还得 □，须满十，8+□=10+□ 不成立 → 排除
试 ○=9：个位 18 写 8 进 1；十位 8+□+1=9 → □=0；百位 9+△=10 → △=1
所以 ○=9，□=0，△=1，验算 989+109=1098
💡 图形算式先定个位，用「试一试 + 排除」定下唯一可能。

🌱 认知练7：一号车 198 棵，二号车 265 棵。一共多少棵？二号车比一号车多多少棵？ 看解析
🤔 想一想
怎么想的：先分清两问：求总数把两车合并，用加法；求相差多少，用大数减小数。算完各写一句答语，单位是棵。
解析：
一共：198+265=463（棵）
个位 8+5=13，写 3 进 1；十位 9+6+1=16，写 6 进 1；百位 1+2+1=4
多多少：265-198=67（棵）
个位 5-8 不够，退位 15-8=7；十位 6 退 1 剩 5，5-9 不够再退，15-9=6；百位 2 退 1 剩 1，1-1=0
💡 验算：67+198=265。
「比……多多少」用减法，不是加法。
✨ 认知练9：156+199 怎样算更快？537-398 为什么最后要加 2？ 看解析
🤔 想一想
怎么想的：先看两个数谁最接近整百，把 199 看成 200 减 1、398 看成 400 减 2；再算整百，最后把多加或多减的那一点补回来。
解析：
156+199 = 156+200-1 = 356-1 = 355（多加 1 要减回 1）
537-398 = 537-400+2 = 137+2 = 139（多减 2 要加回 2）
对比同组两题：156+199=355，156+200-1=355；537-398=139，537-400+2=139，结果完全一样。
💡 巧算口诀：先凑整百，多加就减，多减就加。
竖式也能算对，但巧算在口算和检查时更快。
🔢 强化练8(2)：□□4-42□=471，三个方框各填几？为什么从个位想起？ 看解析
🤔 想一想
怎么想的：先从个位定数，个位定下来才知道要不要退位；再顺着十位、百位往上填，每填一位都用加减关系回代检查。
解析：
个位：4-□=1 → □=3（不需退位）
十位：□-2=7 → □=9
百位：□-4=4 → □=8
所以 894-423=471
验算：471+423=894，与被减数相同。
易错：若个位填 3 却当成退了位，十位就会多算 1，整题都错。
减法填数：个位先看要不要退，退位会影响前一位。
🔺 强化练12：○8○+△□○=△□○8，○、□、△各是几？为什么先定 ○？ 看解析
🤔 想一想
怎么想的：相同的图形填相同的数，个位两个 ○ 相加最独立，先从个位试出 ○ 的两种可能；再用十位排除不合的，最后定百位。
解析：
个位 ○+○ 得 8 → ○=4（不进位）或 ○=9（9+9=18）
试 ○=4：十位 8+□ 要还得 □，必满十，8+□=10+□ 不成立 → 排除
试 ○=9：个位 18 写 8 进 1；十位 8+□+1=9 → □=0；百位 9+△=10 → △=1
所以 ○=9、□=0、△=1，验算 989+109=1098，与右边 △□○8 完全对上。
💡 图形算式常用两步：先试个位，再用排除法去掉不可能。
千位上的 1 来自百位 9+1=10 的进位，别漏写。
🧮 强化练10：只摆最高位，摆出的两个数的和、差各接近多少？说说你的方法。 看解析
🤔 想一想
怎么想的：只摆最高位，就没有十位、个位的数，可以把它看成一个整千数；把两个整千数相加、相减，就得到接近的和与差。
解析：
图上左百位 6、右百位 3 → 看成 6000 与 3000
和接近 9000；差接近 3000
换卡片 2 与 9 → 2000 与 9000 → 和接近 11000，差接近 7000
这是一道开放题：卡片不同，估出的数也不同，没有唯一答案。
💡 说清三句话就得满分：看成哪两个整千数 → 和接近多少 → 差接近多少。
估算是「接近多少」，不必算出精确结果。
✍️ 拓展请你自编一道可以用巧算的加减题，写出巧算过程并验算。 看解析
🤔 想一想
怎么想的：先挑一个接近整百的数（199、198、297、398 这类），再配一个三位数；把接近整百的数写成整百加减几，算完补回差数。
解析：
示例一：347+198 = 347+200-2 = 547-2 = 545
示例二：632-297 = 632-300+3 = 332+3 = 335
验算：545-198=347；335+297=632，都对。
编题要点：① 其中一个数要接近整百；② 说清是多加还是多减；③ 补回时符号相反。
💡 用竖式再算一遍，两种方法结果相同，题才编得稳。
开放题：题目可以不同，只要巧算过程合理、验算通过。
