例3什么是线段？ 看答案 ▾
把线拉直，就得到一条线段；
黑板的边、桌子的边、书的边，都是直的、有头的，都可以看作线段；
弯弯的绳子、毛线没拉直时不是线段。
表示法线段怎么画？ 看答案 ▾
画一条直直的线，两头各有一个小端点；
线段可以横着画、竖着画、斜着画，只要直就行；
💡 两个端点 + 直 = 线段的标志
量线段线段能量长度 看答案 ▾
线段直、有两个端点，所以可以用尺子量；
量法：刻度 0 对准一个端点，看另一个端点对着几；
书上三条线段请你自己用尺量一量，把结果写在书上。
试一试画 3 厘米长的线段 看答案 ▾
① 先点一个端点，对准尺子的刻度 0；
② 笔贴着尺子，从 0 画到 3；
③ 再点一个端点。这条线段就是 3 厘米。

特点：直的、有两个端点、可以量出长度。
✏️ 认知怎么画一条 3 厘米长的线段？ 看解析
🤔 想一想
解析：
从刻度 0 画起，画到刻度 3；
别忘了在两端点端点，这条线段就是 3 厘米。
🏫 强化为什么黑板的边、桌子的边可以看作线段？ 看解析
🤔 想一想
解析：
它们都是直的，有起点和终点；
所以都是线段。窗框边、门框边也是。
📐 强化为什么线段可以量出长度？ 看解析
🤔 想一想
解析：
线段直、两端固定，长度不变；
弯的线一拉就变长，长度不固定，所以不好量。
📏 强化用尺子量线段，怎么量才准？ 看解析
🤔 想一想
解析：
刻度 0 对准一个端点；
尺子贴紧线段，看另一端对着几就是几厘米。
🌈 拓展斜着放的 3 厘米线段还是 3 厘米吗？ 看解析
🤔 想一想
解析：
还是 3 厘米；线段方向不影响长度；
从刻度 0 到刻度 3，横着、竖着、斜着画都是 3 厘米。
🌈 线段看"直"和"长度"，不看方向
