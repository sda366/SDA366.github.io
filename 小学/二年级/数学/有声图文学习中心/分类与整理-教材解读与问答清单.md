- **核心目标**：认识"分类整理"的价值；学会**按不同标准分类**；把分类结果**整理成表格/图**；体会"分类标准不同，结果可能不同，但总数不变"；学会**逐层分类**（先按 A 分、再按 B 分，越分越细）。

## 三、生成问答清单（16 题 · 三层）

### 场景1 生活中的分类与分组（第2～3页）
**认知层**
1. 把蔬菜分类，可以按什么标准分？分完哪种最多、哪种最少？
   → 按**种类**分（西红柿/黄瓜/青椒/洋葱/胡萝卜），数一数比多少。
2. 分两组做游戏，两个小朋友分别想怎样分组？
   → 女生按**大人/孩子**分；男生按**性别**（男/女）分。
**强化层**
3. 大人8人、孩子6人，一共有多少人？ → 8+6=**14（人）**。
4. 对比两种分组结果，你发现了什么？ → **标准不同结果可能不同，但总数不变**（都是14人）。
**拓展层**
5. 🌈 生活中还有哪些分类整理？有什么好处？ → 整理书包/衣柜/玩具…；更容易找到、更容易数出每类。

### 场景2 纽扣盒里的分类（第4～5页）
**认知层**
6. 打翻纽扣盒，先按什么标准分？ → 先按**形状**（方/圆），也可先按颜色（标准不唯一）。
7. 按形状分完，还能继续分吗？ → 能，再按**颜色**（红/蓝）分，越分越细。
**强化层**
8. 先形状、再颜色的"逐层分类"有什么好处？ → 更方便使用，能很快找到做新衣需要的**2粒相同扣子**。

### 场景3 分类的发现与练一练（第6～7页）
**认知层**
9. 卡片先按形状分类，可以怎样分？（做一做） → 按卡片图案形状（桃/梨/苹果）分，结果记录入表。
**强化层**
10. 不管按什么顺序分，最后都成8类，你发现什么？ → 标准确定则结果确定；按一定标准分后还可再分。
11. 练一练1：把车圈出来，哪些不是车？共几辆？ → 不是车：直升机/帆船/飞机/轮船；是车：公交/货车/小汽车/面包车，共**4辆**（⚠待核对）。
**拓展层**
12. 🌈 练一练2：整理自己的书包，怎样整理？ → 按科目/大小/常用不常用分（开放）。

### 场景4 练一练·我会应用（第8～9页）
**认知层**
13. 练一练4：交通标志可以按什么标准分？ → 按**形状**（长/三角/圆），也可按**颜色**。
**强化层**
14. 练一练5：减法算式分两类，怎样分？ → 不唯一：按"减数是一位数/两位数"，或按"是否退位"。
15. 练一练7：图形分两类，可继续分吗？ → 分**平面/立体**两类；立体还可按形状继续分。
**拓展层**
16. 📔 成长小档案：本单元你想说什么？ → 会按不同标准分；有些结果可再分（逐层）；用图表表示更清楚。
